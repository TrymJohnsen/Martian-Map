# 30-second demo script (English)

**Working title: Clean Approach**

| Time | Voiceover | On-screen text / action |
|---|---|---|
| 0–4 s | “What if we disturb the sample before we collect it?” | Show Jezero terrain; label: “Illustrative sample site”. |
| 4–10 s | “This surface comes from Mars Reconnaissance Orbiter CTX.” | Tilt/rotate terrain. Small source label: “20.16 m grid · broad context”. |
| 10–17 s | “Choose the order: collect first, or scout across the marked site first.” | Toggle the two route orders; route, profile and event sequence update. |
| 17–23 s | “The map shows where the route crosses the target footprint—not how much contamination moves.” | Highlight overlap; label: “Potential contact opportunity · scenario only”. |
| 23–27 s | “Perseverance used witness tubes to record the environment near sampling.” | Show the NASA CacheCam witness-tube reference with credit. |
| 27–30 s | “Clean Approach makes the plan—and its assumptions—visible.” | End card: “No contamination or safety score”. |

All key text remains on screen long enough to read. The animation is a scenario, not a measured plume. If the NASA Photojournal image cannot load, keep its caption and citation visible and use the local CTX scene throughout.
