# 30-second demo script (English)

**Working title: Clean Approach**

| Time | Voiceover | On-screen text / action |
|---|---|---|
| 0–4 s | “What could reach Sapphire Canyon through a sequence of contacts?” | Show the documented sample-site coordinate on the MRO/CTX surface and the S → A → B route. |
| 4–9 s | “Perseverance collected sample 25 here at Bright Angel. Site A is our hypothetical earlier sample stop.” | Point to B's PDS source note, then A's illustrative label. |
| 9–18 s | “With one tool shared between A and B, both A-origin and human-associated sources have an assumed path to B.” | Select Plan A and inspect the event trace for Sapphire Canyon. |
| 18–24 s | “A separate tool alone leaves the modeled glove contact. What if this one contact could be avoided?” | Select Plan B, then C. Point out the unchanged route and changed source-path chips. |
| 24–30 s | “These are event assumptions, not measured transfer or a validated EVA procedure. The PDS report does not state location accuracy.” | Show the target note or trace caveat; leave the illustrative A label visible. |

The app does not display a contamination plume, transfer amount, probability, or safety result. MEDA wind remains background only.
