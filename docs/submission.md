# Submission guide summary

Based on the team's copy of the organizer's **Project Submission Guide dated 13 November 2026**. The team is GitWarriors, registered for a Universal Event. The owner lives in Norway, so the submission window follows local Norwegian time.

## Window and destination

- Opens **14 November 2026 at 09:00** and closes **15 November 2026 at 23:59**, Europe/Oslo.
- Edit the project page under **My Team → Project → Edit**.
- Save Progress does not submit. Complete the required fields, accept the terms and originality confirmation, then press **Submit for Judging** before the deadline. Submissions can be edited and resubmitted until then.
- All team members must be confirmed participants at the same event to qualify for awards.

## Demo and links

A demo is required: either a video of no more than 30 seconds, or a presentation of no more than seven slides including title and introduction slides. Exceeding the limit makes a project ineligible for Global Judging. The form has separate fields for the demo and final project links. Videos and documents must be hosted externally and accessible publicly without login or an access request.

The project page and linked materials must be in English. A video may use another spoken language if it includes English subtitles. Per the guide, the demo and final project must not contain images, video, audio, or other depictions of people under 18.

## Form fields

The guide names these fields; this summary does not infer field lengths or which individual fields are mandatory:

- Project Name
- High-Level Project Summary
- Link to Project Demo
- Link to Final Project
- Detailed Project Description
- Use of Super Intelligence (SI)
- NASA Data
- Space Agency Partner Data and Other References

## Judging and certificates

Judging criteria are **Impact, Creativity, Validity, Relevance, and Presentation**. The guide provides no weights in the information summarized here.

After submission, each participant can download a certificate from their profile under **Participant Information → Download Participant Certificate**. The certificate name comes from the profile's **Full Name** field.
