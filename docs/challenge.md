# Challenge summary

**Challenge:** Interplanetary Survival Guide: Martian Map  
**Official page:** [NASA Space Apps Challenge 2026](https://www.spaceappschallenge.org/2026/challenges/interplanetary-survival-guide-martian-map/)

## Core task

Create an integrated, layered view of a place or route on Mars using data from multiple NASA science missions. It should help a human explorer plan and carry out a Marswalk and conduct science along the way. Choose a bounded location and a clear scientific purpose.

## Suggested approaches (optional)

- The result may be a map, tool, or interface.
- The prompt suggests considering at least three data types; this is a recommendation, not a hard minimum. Examples include optical imagery, thermal and spectral observations, topography, geophysics, atmosphere, radiation, and chemistry.
- Astronaut safety and spacesuit mobility are relevant. A route map is suggested where possible.
- Possible formats include a static view, interactive website, habitat display, tablet interface, or helmet display.
- Login, a backend, real-time data, and a complete operational navigation system are not required.
- Historical data and clearly labelled future scenarios are allowed. A simplified model must not be described as validated for astronaut safety.

## Resources listed in the challenge

These are entry points, not necessarily direct downloads or APIs. Check relevance before using them; in particular, do not assume Worldview contains Mars data.
